# AI Provider ToS Compliance Checklist

## Our Operating Model (Safe Harbor)

We operate as a "product built on AI APIs" — not as an API reseller.

✅ We hold all API keys — users never receive or see provider API keys
✅ Users authenticate to OUR platform with OUR credentials
✅ We build a complete product with our own auth, billing, and UI
✅ We do not claim to be OpenAI/Anthropic/Google
✅ We do not train models on user conversations
✅ We enforce our own content moderation layer
